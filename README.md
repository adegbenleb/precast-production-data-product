# Production data product for precast elements (practice project)

A practice project with **simulated data**, built on Databricks Free Edition to learn an end-to-end production data product: bronze, silver, and gold layers with Delta Lake and dbt, a governed metric layer with a Unity Catalog metric view, an AI/BI dashboard, and a Genie space for natural-language questions.

See `docs/PROJECT_SPEC.md` for the requirements and `docs/LEARNING_LOG.md` for the real problems solved along the way.
